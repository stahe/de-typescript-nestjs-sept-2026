# Einführung in die Sprache TypeScript und das Framework NestJS

> ⚠️ **Dieses Repository ist kein Softwareprojekt.** Es gibt keine Anwendung zu installieren, kein Paket zu veröffentlichen und keine Code-Issues zu beheben: Es handelt sich um **Kursmaterial**, geschrieben für Lernende, die TypeScript und anschließend das Framework NestJS erlernen.

## 📖 Den Kurs lesen

Der Kurs kann online unter dieser Adresse gelesen werden:

**👉 [https://stahe.github.io/de-typescript-nestjs-sept-2026/](https://stahe.github.io/de-typescript-nestjs-sept-2026/)**

Zum Lesen ist keine Installation erforderlich: Ein einfacher Browser genügt.

## 🎯 Für wen ist dieser Kurs?

Dieser Kurs richtet sich an Lernende **ohne Vorkenntnisse** in TypeScript oder NestJS. Er beginnt mit den Grundlagen der Sprache TypeScript und führt schrittweise zum Aufbau vollständiger Anwendungen mit dem Framework NestJS, anhand zahlreicher, zeilenweise vollständig kommentierter Codebeispiele.

## 📚 Kursgliederung

Der Kurs ist in große Abschnitte gegliedert:

1. **Die Grundlagen von TypeScript** — Einrichtung der Entwicklungsumgebung,
   Syntax der Sprache, statische Typisierung, objektorientierte Programmierung.
2. **HTTP-Funktionen in TypeScript** — Aufbau eines HTTP-Servers und eines HTTP-Clients
   in reinem TypeScript, bevor ein Framework eingeführt wird.
3. **Datenbankzugriff** — ein Vergleich dreier Ansätze: des nativen
   `mysql2`, des ORM [TypeORM](https://typeorm.io/) und des ORM [Prisma](https://www.prisma.io/).
4. **Das Framework NestJS** — Einführung in das Framework, seine MVC-Architektur,
   Request-Verarbeitung (Actions/Antworten), die Modellschicht und den Datenzugriff
   mit NestJS.
5. **Eine umfassende Fallstudie** — die Portierung eines ursprünglich in PHP geschriebenen Servers zur Einkommensteuerberechnung nach NestJS: Controller, DAO- und
   Geschäftslogikschichten, Sitzungsverwaltung und der Aufbau von HTML-Seiten mit EJS-Templates.
